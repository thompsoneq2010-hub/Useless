# The Raven Creek Tapes — Website

Free static website for the fictional found-footage horror film **The Raven Creek Tapes**.

## Pages
- `index.html` — main archive
- `history.html` — Raven Creek history
- `1975.html` — original 1975 incident
- `1990.html` — main 1990 investigation
- `characters.html` — Elijah, Aiden, Lucas, Steven, Colin and Noah
- `evidence.html` — cult, legend, asylum and future evidence
- `archive.html` — document index
- `film.html` — film/trilogy/production information

## Adding posters
Put poster images in `assets/posters/`, then replace the `PHOTO PENDING` placeholders in `characters.html`.

## Adding evidence
Put images, screenshots, documents and other media in the appropriate `assets/` folders.

## GitHub Pages
1. Upload all files to a GitHub repository.
2. Go to **Settings → Pages**.
3. Choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`.
5. Save.

## Before publishing
Replace the temporary GoFundMe and Amazon links with the project's real links.
